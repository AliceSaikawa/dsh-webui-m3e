# 07 検索タブ

## 目的

過去のセッションを、中身の言葉から探せるようにします。

## 担当する画面

| Canvas の画面 id | 名前 |
|---|---|
| `search` | 検索 |

仕様は `docs/ui-spec.md` の「検索タブ」の節です。

## 担当するファイル

- `web/src/features/search/` の全部（`routes.tsx` と `SearchScreen.tsx` は 00 の仮の部品を置き換える）
- `tests/07-*.test.ts`
- この設計書の「実装メモ」

## 入口

`routes`：`#/search`（下のタブ、`tab: 'search'`）。

## 画面の中身

- 上のバー「検索」の下に、検索バー「セッションを検索」を置きます。タブを開いたら検索バーに入力できる状態にしますが、キーボードを自動では出しません（iOS では画面が動くため）。
- **検索の呼び方**：入力が止まって 300ms 待ってから `sessions.search(query, signal)` を呼びます。新しい入力があったら、前の問い合わせを `AbortSignal` で中断します。空白だけの入力では検索しません。
- **結果の行**
  - 1 行目：セッションの題名。
  - 2 行目：一致した箇所の抜粋。一致した語を太字にします。抜粋が結果に入っていない場合は、「作業フォルダ名 ・ 最終更新日時」を出します（「未確認のこと」を見てください）。
  - 左のアイコンは、01 の一覧と同じモデルのアイコンです。01 の部品を読み込まず、`sessions.list` の `projectionValues` がなければ汎用のアイコンで構いません。
  - タップで `#/s/<id>` へ移ります。戻ると、検索の文字と結果、スクロール位置が残っています。
- 結果の上に「「<語>」の検索結果」と出します。
- `hasMore` が true のときだけ、最後に「さらに読み込む」を出します。押し方は「未確認のこと」を見てください。
- 検索中は検索バーの下に細い進捗バーを出します。
- 結果が 0 件なら「見つかりませんでした」。検索に失敗したら、理由と「もう一度検索」を出します。
- 何も入れていないときは、最近開いたセッション（`sessions.list` の `updatedAt` の新しい順に 5 件）を「最近のセッション」として出します。

## 使う DSH の窓口

- `sessions.search(query, signal)`：`RemoteResult<{ items: SessionSearchResultItem[]; hasMore: boolean }>`、上限は `sessions.searchResultLimit`
- `sessions.list`
- 00 の `navigate`

参考の実装：今の画面で検索を使っている部分（`dsh-client-ui-sidebar` など）。`SessionSearchResultItem` の中身はここで確かめてください。

## 偽データ（mock.ts）

- `kit.patch('sessions.search', …)` で偽の実装に差し替えます。セッションの題名と履歴の本文から語を探し、前後 20 文字を抜粋にして返します。応答を 400ms 遅らせ、中断を受けたら結果を返しません。
- 「承認」で 3 件、「zzz」で 0 件になるようにします。
- `?mock&scenario=search-error`：検索が失敗を返します。

## テスト

`tests/07-search.test.ts` で、次の純粋な処理を確かめます。

- 抜粋の中の一致した語の位置を探して、太字にする範囲を返す処理（大文字小文字、複数回の一致、一致なし）
- 検索するかの判定（空白だけ、前と同じ語）
- 「最近のセッション」の選び方

## 完了条件

- `?mock` で、入力に合わせた検索、中断、結果からの移動と戻り、0 件、失敗、最近のセッションが動きます。
- `pnpm typecheck`、`pnpm test`、`pnpm build` が通ります。

## 未確認のこと

- `SessionSearchResultItem` に抜粋（一致した箇所）が入っているか。入っていなければ、2 行目は作業フォルダ名と日時にします。
- 「さらに読み込む」の方法。`search` には続きを取る引数がありません。上限を上げて取り直すのか、続きは取れないのかを確かめ、取れなければ「さらに読み込む」の代わりに「さらに結果があります。語を増やして絞り込んでください」と出します。
