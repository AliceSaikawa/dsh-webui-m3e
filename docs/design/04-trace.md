# 04 トレースタブ

## 目的

会話の記録を、ターンごと、処理ごとに並べて、どこで時間とトークンを使ったかを見られるようにします。今の PC 版の画面の「トレース」（`dsh-client-ui-trajectory`）をスマートフォン向けにしたものです。

## 担当する画面

| Canvas の画面 id | 名前 |
|---|---|
| `trace` | トレース |
| `record` | 記録の詳細 |

仕様は `docs/ui-spec.md` の「トレースタブ」の節です。

## 担当するファイル

- `web/src/features/trace/` の全部（`TraceView.tsx` は 00 の仮の部品を置き換える）
- `tests/04-*.test.ts`
- この設計書の「実装メモ」

## 入口

`TraceView({ sessionId })`。00 の会話画面がタブ「トレース」のときに描きます。このとき入力欄は出ません。

## 画面の中身

### 並べるもの

`useSession(sessionId)` の `records` と `stream` から、ターンごとの記録の列を作ります。

- **ターンの見出し**：`turn/start` から `turn/end` までを 1 つのターンとします。見出しは「ターン N ・ 合計 x 秒 ・ y トークン」。実行中のターンは「ターン N ・ 実行中」。
- **記録の行**：次の種類を 1 行ずつ出します。
  - ユーザー：`user/message`。2 行目に本文の先頭。
  - アシスタント：`assistant/message`。2 行目に所要時間と出力トークン。
  - ツール：`tool/call` と `tool/result` の組。1 行目は「ツール：<名前>」、2 行目に所要時間。失敗（`isError` か `error`）は色と「失敗」で示します。
  - サブツール：サブエージェントの中のツールなど、入れ子の記録。字下げして出します。
  - 要約（compaction）：会話を短くまとめた記録。
- 実行中の記録には開始の印だけを出し、経過時間を数えません。
- 画面に残らなかった試行（`assistant/attempt`）は、アシスタントの行に「再試行 n 回」と添えます。

### 時間とトークン

- 所要時間はイベントの `time` の差から出します。アシスタントは `step/start` から `assistant/message` まで、ツールは `tool/call` から `tool/result` までです。
- 最初の出力までの時間は、`assistant/message` の `stream` の最初の記録の時刻から出します。
- トークンは `assistant/message` の `usage`（入力、出力、キャッシュの読み書き）です。ターンの合計は、そのターンのアシスタントの `usage` を足したものです。

### スクロール

- 開いたときは最新の記録（一番下）から出します。生成中は、一番下にいる間だけ末尾を追いかけます。上にスクロールしたら追いかけるのをやめます。
- 一番上に「前の記録を読み込む」ボタンを置き、`hasMore` が true のときだけ出します。押すと `loadOlder()` を呼びます。

### 下の検索バー

- 入力欄の代わりに、画面の下に検索バーを置きます（ユーザーが Canvas で追加）。
- 入れた文字で記録の行を絞り込みます。対象は、記録の種類の名前、ツール名、本文です。絞り込み中も、ターンの見出しは残します。
- キーボードが出たら、検索バーはキーボードのすぐ上に来ます（00 の `viewport.ts`）。

### 記録の詳細

- 行をタップすると、下からシートを開きます。
- アシスタントの記録：所要時間（最初の出力までの時間を含む）、トークン（入力・出力・キャッシュ）、入力（送ったメッセージとツールの結果）、出力（思考・テキスト・ツール呼び出しの数）。入力と出力は、タップで中身を開きます。
- ツールの記録：引数（JSON を整形して等幅で。トレースでは引数を見られる）、結果、所要時間。
- ユーザーの記録：本文と添付。
- PC 版にある時間軸の図（ドラッグで範囲を選ぶもの）は作りません。

### 承認と質問

トレースを表示中でも、承認と質問のシートはその場で開きます。これは 00 の会話画面が扱うので、この機能では何もしません。

## 使う DSH の窓口

- 00 の `useSession(sessionId)`：`records`、`stream`、`snapshot.hasMore`、`snapshot.loadingOlder`、`face.loadOlder()`
- 00 の `openSheet`

参考の実装：今の画面の `dsh-client-ui-trajectory`。記録の種類の見分け方と、所要時間の出し方はこれに合わせてください。

## 偽データ（mock.ts）

- 「承認シートの実装」の履歴（`trace` の中身）は 00 が用意済みです。この機能では書き換えません。
- 別のセッション「トレースの見本」を足し、再試行の記録（`assistant/attempt`）、要約の記録、サブエージェントの中のツール（サブツール）、長いターン（前の記録を 1 回読み込める長さ）を入れます。

## テスト

`tests/04-trace.test.ts` で、次の純粋な処理を確かめます。

- `records` からターンと記録の行を作る処理（ターンの区切り、`tool/call` と `tool/result` の組み合わせ、実行中のターン、再試行の数え方）
- 所要時間、最初の出力までの時間、ターンの合計トークンの計算
- 検索の文字での絞り込み（見出しを残す）

## 完了条件

- `?mock` で、ターンの見出し、各種の行、失敗の色、実行中の印、前の記録の読み込み、検索での絞り込み、記録の詳細のシートが動きます。
- チャットに戻ると、トレースを開く前の表示に戻ります（00 の会話画面の動き）。
- `pnpm typecheck`、`pnpm test`、`pnpm build` が通ります。

## 未確認のこと

- 要約（compaction）とサブツールの記録が、どのイベントの種類で届くか。`dsh-client-ui-trajectory` を読んで確かめてください。
- `assistant/message` の `stream` の記録に時刻があるか。なければ、最初の出力までの時間は出しません。
