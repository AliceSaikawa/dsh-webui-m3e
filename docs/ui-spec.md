# 画面の仕様

2026-09-25 に、この仕様と Canvas の最新版（41 画面）を現段階の決定としました。機能ごとの設計書は `docs/design/` にあります。細かい見た目と文言は、実装したものを見てフィードバックで詰めます。

M3E Canvas のモックと、会話で決めたことをまとめたものです。データの出どころは `~/AI/inbox/2026-09-17-dsh-webui-m3e-api-surface.md`（DSH 0.1.5-rc.1 の API 調査）を正とします。

## セッション一覧（ホーム）

- **上のバー**：左に ≡、中央にタイトル、右に ⋮ を置きます。
  - ≡ はワークスペースを切り替えるドロワーを開きます（下の「ワークスペースの切り替え」）。
  - タイトルは、今いるワークスペースの名前です。
  - ⋮ の中身は下の「一覧の ⋮ メニュー」のとおりです。
- **一覧の行**
  - 左のアイコンは、そのセッションのモデルのアイコンです。`projectionValues.modelSelection.lastUsed` の提供元とモデル名から選びます。アイコンは SVG で同梱し、該当がなければモデル名の頭文字を出します。値のない行もありえます。
  - アイコンの右下に状態の印を重ねます。対象は、実行中、完了して未読、承認待ち・質問待ちです。
  - 1 行目はタイトル（`displayTitle`）、2 行目は「作業フォルダ名 ・ 最終更新日時」です。最後のメッセージは一覧のデータにないので出しません。
  - 横スワイプでアーカイブします（任意）。
- **右下の FAB**：＋ で「新しいセッション」の画面を開きます。今のワークスペースに作ります。
- **ナビゲーションバー**：一覧、検索、対応待ち、設定の 4 つで、この順に並べます。
  - ラベルは「一覧」「検索」「対応待ち」「設定」です。
  - 対応待ちのアイコンは手のひら（`front_hand` 系）で、件数のバッジを付けます。
- **余白**：一覧の最後の行が、FAB、ナビゲーションバー、iPhone のホームバーに隠れないようにします。

## ワークスペースの切り替え

- 一覧の ≡ で、左から出るナビゲーションドロワーです。右側は暗くし、タップすると閉じます。
- ワークスペースを並べ、今のものを選択中の見た目にします。1 行は名前とフォルダの場所です。選ぶと一覧がそのワークスペースに切り替わります。
- 長押しで、名前の変更（`workspace.rename`）、並べ替え（`insertBefore`）、登録の解除（`workspace.delete`）を選べます。登録を解除しても、フォルダの中身は消えません。
- 最後の行は「ワークスペースを追加」で、「フォルダの選択」を開きます。

## フォルダの選択

- DSH が動いている機械のフォルダを、1 階層ずつたどって選びます（`directoryPicker` の `browse`）。iPhone からは OS のフォルダ選択（`native`）が使えないためです。`directoryPicker` が使えないときは、「ワークスペースを追加」自体を出しません。
- 上に閉じるボタン、その下にパンくず（今いる階層までの道のり。タップでその階層に戻る）を置きます。
- フォルダの行をタップすると 1 階層下に入ります。隠しフォルダは出しません。1,000 件を超えると一部だけになる（`truncated`）ことを小さく知らせます。
- 下に「新しいフォルダ」（`createDirectory`）と「ここを追加」（`workspace.create`。登録済みなら既存のものを返す）の 2 つのボタンを並べます。

## 新しいセッション

- 一覧の ＋ で開く、まだ何も話していない会話です。中央に「何をしますか」と、どのワークスペースで始めるかを出します。入力欄は会話画面と同じです。
- **セッションは、最初のメッセージを送った時点で作ります**（`sessions.create`。2026-09-25 決定）。何も送らずに戻ったら作りません。空のセッションを一覧に残さないためです。

## 一覧の ⋮ メニュー

中身は下の「有力な候補」の 4 つです（2026-09-25 決定）。項目を選ぶか、外側をタップすると閉じます。検討した候補と、それぞれの根拠は次のとおりです。

- 有力な候補
  - **並べ替え**：一覧の手動の並び順を変えるモードに入ります。ワークスペースが手動順（`sessionIds`、`insertSessionBefore`）を持っているので作れます。
  - **選んでアーカイブ**：複数の行を選んで、まとめてアーカイブします（`archiveSession` を 1 件ずつ呼ぶ）。
  - **ワークスペースの名前を変える**：今のワークスペースに対する操作です。ドロワーの長押しと同じ操作を、見つけやすい場所にも置きます。
  - **サブエージェントのセッションを表示**：切り替えスイッチです。一覧の 1 件は `origin: 'subagent'` と `parentId` を持てるので、隠すか出すかを選べます。一覧に実際にサブエージェントの行が来るかは未確認です。
- 保留する候補
  - **アーカイブ済みを表示**：アーカイブ済みの一覧（`archivedSessionIds`）は取れます。ただし、アーカイブを戻す専用の API は、Mac の DSH 0.1.5-rc.1 の型定義にありません。`insertSessionBefore` で戻せるかは未確認です。見られても戻せないなら、価値が下がります。
- 外す候補
  - **読み直す**（`sessions.refresh`）：一覧を下に引っぱって読み直す操作で足ります。
  - **再接続**：接続が切れたときのバナーにボタンがあります。
  - **使用量・クォータ**：第 1 弾ではクォータを出さない方針です（API 調査メモ §9.10）。トークン数もセッションごとの値で、一覧全体の値はありません。

## 接続が切れたとき

- 一覧の上のバーの下にバナーを出します。中身は「DSH との接続が切れました」、表示しているデータが何分前のものか、「再接続」ボタン（`connection.reconnect()`）です。
- 再接続の途中は、上のバーの下に細い進捗バーだけを出し、失敗したらバナーに切り替えます。PWA を裏に回して戻ると再接続が走るので、状態を出さないと固まったように見えるためです。
- 接続が切れている間は、＋ ボタンを押せなくします。

## 検索タブ

- セッションを全文検索します（`sessions.search`）。ファイルの中身は検索できません。
- 上に検索バーを置きます。入力を止めて少し待ってから検索し、前の検索は取り消します（`AbortSignal`）。
- 結果の行は、1 行目が題名、2 行目が一致した箇所の抜粋で、一致した語を強調します。結果の 1 件に抜粋が入っているか（`SessionSearchResultItem` の中身）は未確認です。
- `hasMore` が true のときだけ、最後に「さらに読み込む」を出します。

## 対応待ちタブ

- 自分の操作が必要なセッションだけを並べます。対象は、ツールの承認待ち、AI からの質問待ち、プランの承認待ち、完了して未読のものです。
- 2 つの区分に分けます。「返事が必要」（承認・質問・プランの確認）と「終わったもの」（完了して未読）です。
- 「返事が必要」の行をタップすると、会話を開かずに、承認や質問のシートを対応待ちの画面の上に直接出します。プランの確認は、質問の一種（`intent: plan-review`）として届きます。本文が長いので、全画面のシートにします。
- 「終わったもの」の行をタップすると会話を開きます。開くと既読になり、この画面から消えます。

## 設定タブ

- 上の区分は「この端末」で、この端末だけの設定です。
  - 「今の画面に戻す」：Cookie `dsh-webui` を `classic` にして `/` へ移ります。
  - 「外観」（明暗）：この端末だけで持ち、DSH の `ui-theme` とは共有しません（2026-09-25 決定）。
- 下の区分は「DSH の設定」で、DSH 全体の設定です。名前空間ごとのスキーマから、画面を自動で作ります。12 個の名前空間を次の 5 行に束ねます。
  - モデル：`agent-default-model`、`subagent-model-selection`
  - 権限：`permission`
  - エージェント：`agent-presets`、`agent-loop`
  - 提供元と API キー：`llm-*` と認証情報。キーは書き込むだけで、登録済みかどうかだけを出します。
  - Web 検索とシェル：`web-search-deepseek`、`shell`、`locale`
  - `ui-*` と `ui-onboarding` は今の画面向けなので出しません。
- 設定の詳細ページ
  - 各項目の補足に、反映のタイミングを出します（`applies` が `live` ならすぐ、`restart` なら再起動後）。
  - ユーザーが上書きした項目（`user` に値がある）には「既定値に戻す」を出します。
  - `writable` が false なら、全部の項目を無効にします。書き込みが競合（`settings/conflict`）したら、読み直しを促します。

## そのほかの一覧と設定の画面

- **セッションの操作**：一覧の行を長押しすると開くシートです。「題名を変える」と「アーカイブ」を置きます。行を横にスワイプしてもアーカイブできます。
- **題名を変える**：会話の ⋮ や一覧の長押しから開くダイアログです（`ISession.rename`）。ワークスペースの名前の変更も同じ形にします。
- **セッションがないとき**：一覧の中央に「まだセッションがありません」と出し、＋ へ誘導します。
- **提供元と API キー**：提供元ごとに、キーが登録済みかどうかを出します。キーの入力はシートで、保存（`credentials.set`）と登録の削除（`credentials.unset`）ができます。入力した値は二度と表示しません。
- **外観**：「端末の設定に合わせる」「ライト」「ダーク」をシートで選びます。

## 画面遷移の決まり

- **下のタブ**（一覧・検索・対応待ち・設定）は、どこからでもほかのタブへ切り替わります。切り替えはフェードで、履歴を積みません。
- **奥の画面**（会話、設定の詳細、フォルダの選択、新しいセッション）は右から入ります。左上の ← と左端からのスワイプで、来た画面に戻ります。たとえば検索から開いた会話は、検索に戻ります。
- **シート**（＋、ツール承認、AI からの質問、記録の詳細）は下から出ます。返事をするか下に払うと閉じて、開く前の画面に戻ります。ただし、返事が必要なシートは払っても閉じません。
- **ドロワー**は左から出ます。ワークスペースを選ぶか外側をタップすると閉じます。
- 会話の「チャット / トレース」の切り替えは、同じ会話の中の表示の切り替えです。戻る操作の対象にはしません。
- 送信と停止は、同じ会話の状態（待機中と実行中）を切り替えるだけで、画面は移りません。

## 会話画面

- 上のバーは、戻るボタンとセッションの題名です。ナビゲーションバーは出しません。
- 上のバーの下に「チャット / トレース」のタブを置きます。
- 左端からのスワイプで、来た画面（一覧・検索・対応待ち）に戻ります。

### トレースタブ

- 出どころは今の画面の `dsh-client-ui-trajectory` と同じ記録です。対象は、ユーザー、アシスタント、ツール、サブツール、要約（compaction）です。
- ターンごとに見出しを付けます。見出しには、合計の所要時間とトークン数を添えます。
- 各行には、記録の種類（ツールは名前）、所要時間、トークン数を出します。失敗したツール（`isError`）は色で分かるようにします。
- 最新の記録から表示し、生成中は末尾を追いかけます。上にスクロールしたら追いかけるのをやめます。古い記録は「前の記録を読み込む」で読み込みます。
- 実行中の記録には開始の印だけを出し、経過時間を勝手に数えません。
- 行をタップすると、「記録の詳細」のボトムシートを開きます。中身は所要時間（最初の出力までの時間を含む）、トークン（入力・出力・キャッシュ）、入力、出力です。ツール呼び出しの引数は、トレースでは見られます。
- トレースを表示している間は、入力欄を隠します。送りたいときはチャットに戻ります。
- 入力欄の代わりに、下に検索バーを置きます（ユーザーが Canvas で追加）。トレースの記録を絞り込むものと解釈しています。
- トレースを表示中でも、ツール承認と AI からの質問のシートはその場で開きます。
- PC 版にある時間軸の図（ドラッグで範囲を選ぶもの）は、スマホでは出しません。

### 入力欄

- 角丸 28px の枠 1 つに、入力欄とボタンの行をまとめます。1 行のときの高さは約 110px です。
- 入力欄は最大 6 行まで伸び、それ以上はスクロールします。
- **Enter は改行です。送信はボタンだけです。**
- 下の行
  - 左：＋ ボタンです。ボトムシートを開き、画像添付、ファイル参照（`@`）、コマンド一覧、計画モードを操作し、モデルと考える深さをドロップダウンで選べます。
  - その隣：権限プリセットのチップです。常に表示します。
  - 右：送信ボタンです。
- **AI の実行中**
  - 停止ボタン（`ISession.cancel()`）を出します。
  - 送信ボタンはスプリットボタンにします。主ボタンは「順番待ち」で、▾ から「割り込み」を選べます（`prompt(content, mode)` の 2 つのモード）。
  - 順番待ちのメッセージは、入力欄の上に小さく出します。タップすると、編集、取り消し、割り込みへの変更ができます（`updateQueue`）。
- **候補リスト**：`/` でコマンドの候補（`CommandDescriptor`）、`@` でファイルの候補（`fileReferences.list`）を、入力欄の上に出します。
- **入力欄の外に出すもの**：統計とクォータは ⋮ から開きます。ツール承認と AI からの質問は、入力欄の上にボトムシートで重ね、返事が済むまで入力欄を隠します。
- **キーボード**：入力欄の位置は `visualViewport` に合わせます。画面全体の高さの計算には頼りません。iOS の Simulator でキーボードを出し入れしながら確かめます。

### チャットタブ

- 画面に出すのは `user/message`、`assistant/message`、`tool/result`、`system/message` の 4 種類です。知らない種類は読み飛ばします。
- 自分のメッセージは右寄せの吹き出しにします。添付した画像は小さく出し、タップで全画面に広げます。
- 考えた内容（`reasoning`）は、ふだんは畳んでおき、タップで開きます。
- ツールの呼び出しは 1 行ずつ出します。ツール名に、引数の JSON から主な値を 1 つと、所要時間を添えます。JSON が壊れていたらツール名だけにします。失敗（`isError`）は色で分かるようにします。行をタップすると「ツール呼び出しの詳細」のシート（引数の整形、結果、所要時間）を開きます。
- コマンドの結果（`command/done`）は吹き出しにせず、小さな行で出します。
- メッセージを長押しすると「メッセージの操作」のシートを開きます。中身は「コピー」と「ここから分岐」（`sessions.fork` の `atSeq`）です。
- AI の処理が失敗したとき（`lastAgentError`）は、会話の最後にカードを出します。送信の失敗（`promptError`）は入力欄の上に小さく出して、もう一度送れるようにします。会話を開けなかったとき（`openState: error`）は、画面の中央に理由と「もう一度開く」を出します。

### 入力の補助

- `/` の候補と `@` の候補は、入力欄の上に出す浮いた一覧です。キーボードが出ている前提で、入力欄はキーボードのすぐ上に来ます。
- ＋ のシートの「画像を添付」は iOS の写真選択を開き、選んだ画像を入力欄の中に並べます。送る前なら × で外せます。
- ＋ のシートにモデルのドロップダウンを置きます。モデル一覧の取得中は読み込み中と示し、失敗時は理由と再試行を出します。考える深さは対応モデルを選んだときだけ表示します。
- 実行中の会話では、順番待ちのメッセージをタップすると「順番待ちの編集」のシートを開きます。中身は「編集」「今すぐ割り込ませる」「取り消す」です。

### 返事が必要なシートと選び直し

- **AI からの質問**：選択肢はラジオボタン（複数選択の問いはチェックボックス）で、下に自由入力の欄を置きます。1 回に複数の問いが来たら 1 問ずつ進みます。「あとで」はシートを畳むだけで、質問は対応待ちに残ります。
- **プランの確認**：全画面で開き、プランの本文（Markdown）をスクロールで読みます。ボタンは「直してほしい」（自由入力で修正を頼む）と、`intent.approve` の文字をそのまま使う承認ボタンです。
- **モデルの選択**：＋ のシート内のドロップダウンでモデルと考える深さ（`reasoningEffort`。対応するモデルだけ）を選び、その場で反映します。`/model` の送信では同じドロップダウンを持つシートを開きます。
- **権限の選び直し**：入力欄の権限のチップから開きます。説明文は `PresetOption.description` をそのまま出します。どのプリセットにも合わないときは「カスタム」と表示だけします。「フル アクセス」を選ぶときも確認は挟みません（2026-09-25 決定。実装後のフィードバックで見直す）。

### 会話の ⋮ メニュー

- 項目は「題名を変える」「統計」「ファイル」「ジョブ」「サブエージェント」「ゴール」「アーカイブ」です。
- **統計**：コンテキストの使用率、トークン、ターン数、モデルをシートで出します。値は projection から読みます。クォータは第 1 弾では出しません。
- **ファイル**：作業フォルダの中を読み取り専用でたどり、中身を表示します。テキストは 5,000 行ずつ読みます。
- **ジョブ**：動いているジョブと状態を並べ、実行中のものは止められます。止める API の形は未確認です。
- **サブエージェント**：子のエージェントを並べ、タップで子の会話を会話画面と同じ形で開きます。続けて頼めるものだけ入力欄を出します。
- **ゴール**：目標の文、状態、ラウンド数を出し、「一時停止」「完了にする」「ゴールを消す」を置きます。作成と編集は後回しです。

### ツール承認のシート

- 出せるのはツール名、理由、call id だけです。引数は届きません。
- ボタンは「許可（1 回）」と「拒否」だけです。「常に許可」はありません。

## Canvas のモックと実装の違い

Canvas は構造を確かめるためのもので、部品や動きに制約があります。実装するときは、次の点を Canvas の見た目ではなく、この仕様書に合わせてください。

- **ドロワー**：Canvas にスマートフォン用のドロワーの部品がないので、背景を暗くした画面に四角い枠を置いて描いています。実装では M3 のナビゲーションドロワー（モーダル）にします。
- **対応待ちから開いたシート**：Canvas では、承認のシートの背景が会話画面のままです。実装では、対応待ちの画面の上に出します。
- **戻る操作**：Canvas のスワイプは新しい画面を重ねる動きしかできないので、左端からのスワイプで戻る動きは描いていません。各画面のメモに書いてあります。
- **送信と停止**：Canvas では「待機中」と「実行中」の会話を別の画面として描いていますが、つないでいません。実装では同じ会話の状態の違いです。
- **一覧の行**：Canvas の 2 行目は「AI が実行中のセッション」の例として、実行中の会話につないであります。
